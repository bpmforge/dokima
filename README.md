# Shipwright

**Idea → secure, great product.** A local-first, human-in-the-loop platform where expert AI agents act as your product manager and development team: a guided SDLC program with gated pipelines, per-item micro-loops, cheapest-model-first execution with escalation, a native Kanban engine, and an evidence-based trust model — the platform holds the gates, not the agents.

Productizes three proven internal systems: **bpm-opencode-experts** (the expert/SDLC discipline), **bpm-agent-amplifier** (gate integrity + Conductor economics), and **Foreman/Jarvis** (the autonomous loop runtime).
