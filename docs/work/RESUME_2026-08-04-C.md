## 6. Traps (earlier resumes' traps still apply)

1. **The dev core serves a stale bundle.** `cli-entry.mjs` prefers
   `apps/server/dist/main.js` and never checks its age. `pnpm build` before any
   browser check. `pnpm e2e` is immune (it runs `tsx` against source), so green
   e2e never rules this out.
2. **`return promise` inside `try { … } finally { log.close() }`** closes the
   database under the pending work.
3. **macOS temp dirs are symlinks** (`/var` → `/private/var`); compare
   realpaths, or a repo is not its own root.
4. **zsh does not word-split unquoted variables** — `for f in $FILES` passes
   one argument.
5. **`vitest` does not typecheck.** A fixture using the server's `dId` where
   the web wants `d_id` ran green and only `pnpm typecheck` caught it.
6. **An allowlist drops what it does not copy.** `validateProviderEntry`
   validated a new field and did not carry it — settable and inert. Assert the
   value *survives*, not just that bad input is refused.
7. **Fixtures can be wrong before the code is.** Several of mine were, and the
   product was right each time. Re-read the failure before "fixing" the code.
