## 2. Read this before you trust anything below

**The agentic loop runs. No agent has ever written code with it.**

Every proof in this session used a *fake agent*: a shell script that writes a
hardcoded file, commits it, and prints a Completion Manifest. That is what
Law 9 requires and it exercises the whole machine — claim, worktree, session,
scope check, close gate, receipt, land — but it is not a model doing work.
Nothing in this repo has yet produced a line of code from a model.

Read "the loop works" as **"the harness around an agent works, and the trust
boundary holds when the agent lies."** A real agent will lie differently.

## 6. Traps (the previous resume's 1–7 still apply)

1. **The dev core serves a stale bundle.** `cli-entry.mjs` prefers
   `apps/server/dist/main.js` and never checks its age. Restarting is not
   enough — `pnpm build` first, or you measure the last build, not the last
   commit. This cost the first hour: a restarted core reproduced the exact
   pre-W10-67 failure and looked like the fix not working. `pnpm e2e` is immune
   (it runs `tsx` against source), so green e2e never rules this out.
2. **`return promise` inside `try { … } finally { log.close() }`** closes the
   database out from under the pending work. Cost a confusing "The database
   connection is not open" from deep inside the loop. Await into a local.
3. **macOS temp dirs are symlinks** (`/var` → `/private/var`). Comparing
   `git rev-parse --show-toplevel` to a raw input path decides a repo is not
   its own root. W3-09's lesson; compare realpaths.
4. **zsh does not word-split unquoted variables.** `for f in $FILES` passes the
   whole string as one argument. Cost a bungled red proof.
5. **A refusal piped through `head` reports exit 0.** Trap 2 of the previous
   resume in a new costume — check the real exit code separately.
6. **Fixtures can be wrong before the code is.** Two of mine were: one asserted
   `SELF_ACCEPT` from `in_progress` (the transition guard fires first,
   correctly), one read its ticket from an env var the spawner strips. Both
   times the product was right. Re-read the failure before "fixing" the code.
