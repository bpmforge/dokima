## 4. Traps (new — 1–6 in the previous resume still apply)

1. **The suite reads your real `~/.dokima`.** Making the global settings scope
   resolvable (W10-62/64/70) meant every "nothing configured" test read whatever
   you had configured. Registering a provider through the panel to verify W10-70
   turned `main` red four tests later. Fixed systemically in
   `apps/server/vitest.setup.ts`, but the *lesson* is behavioural: **after
   verifying a feature by configuring something through the product, re-run the
   gate** — that configuration is now part of the environment the suite runs in.
2. **Piping a gate through `tail` masks its exit code.**
   `node scripts/validate-plan.mjs | tail -3 && git commit` turned a FAIL into a
   0 and pushed an invalid `plan.json`. Run gates bare, or check `PIPESTATUS`.
3. **Backticks in commit messages get eaten by the shell.** Trap 6 of the
   previous resume, hit again despite knowing it: a heredoc-less
   `git commit -m "…\`providers\`…"` silently dropped the word. Write the message
   to a file and use `-F`.
4. **`form_input` on a React checkbox does not fire `onChange`.** It sets the DOM
   property, React state never updates, and the form submits with the old value.
   Selects are fine; checkboxes must be *clicked*.
5. **A red proof must revert to the SHIPPED code, not to something worse.**
   Reverting `paneNodes.ts` to `[]` broke 8 specs — but the real prior dep was
   `[projectId]`, which does re-run on project change. The honest proof restores
   the exact file from `HEAD`.
6. **Scope the source file AND its sibling test.** Four `write_scope` corrections
   on W10-64 alone, two of them this same omission. Mechanical rule, apply it
   when filing.
7. **A same-lane `in_progress` ticket blocks its whole lane.** W10-54 sat
   `in_progress` owing one e2e spec and blocked five tickets — including W10-61,
   the one it was waiting for. `validate-plan` refused the claim and surfaced the
   cycle. Resolved by **transferring** the acceptance to W10-61 with the original
   text preserved, not by grading it met or reverting to `todo`.
