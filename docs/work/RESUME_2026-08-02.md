## 4. Traps — every one of these cost real time today

1. **Node 22, always.** `fnm`'s default is 24 and `better-sqlite3`'s native
   binary is built for 22. Node 24 fails ~50 `apps/server` tests with a
   `NODE_MODULE_VERSION 127 vs 137` mismatch **that looks exactly like real
   breakage**.
2. **The signing private key lives OUTSIDE the repo, at a stale-looking path:**
   `~/.shipwright/keys/shipwright-signing-key.pem` (0600). It predates the
   rename and was deliberately not moved — moving it silently would strand
   anyone following this note. To re-sign content after editing anything under
   `content/validators/`:
   ```sh
   DOKIMA_SIGNING_KEY="$(cat ~/.shipwright/keys/shipwright-signing-key.pem)" \
     node scripts/sign-content.mjs
   ```
   **Any byte change under `content/validators/` invalidates the manifest hash
   and fails 5 pack-integrity tests until you re-sign.** That is exactly what
   blocked W9-08 for five days.
3. **zsh does NOT word-split unquoted parameters.** `for c in "providers refresh"; do cmd $c` passes ONE argument, not two. This produced a
   convincing false bug report about the CLI booting a server, and separately
   broke a `whois` wrapper into reporting every domain as registered. If a
   loop-driven CLI check gives a weird result, suspect this first.
4. **`pnpm test` alone is not the gate.** Vitest does not typecheck. Two
   `ProjectCard` fixtures were missing a newly-required field and only `tsc`
   caught it. Law 3 runs lint + typecheck + test + e2e for this reason.
5. **A safety hook blocks `git push --force`** (`~/.claude/hooks/block-dangerous.py`). Verbal authorization does not lift it — it is a
   mechanical gate. The user must run force-pushes themselves.
6. **Mutation testing only proves something if you break the RIGHT subject.**
   In W9-08 the first Defect-2 mutation hit the catch-block `parseNdjson` call
   (the pre-existing multi-line path) and redded the *two-line* test while the
   dedicated single-line fixture stayed green. Retargeting at the fallthrough
   redded the correct tests. Always check *which* tests went red.
