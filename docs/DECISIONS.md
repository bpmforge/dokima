| D-022 | 2026-08-03 | **License: FSL-1.1-ALv2** (Functional Source License, Apache-2.0 future licence) for Dokima's own source, superseding D-017. Bundled `content/` stays Apache-2.0 (imported from `attest`; notices preserved at `content/LICENSE`). `package.json` declares `SEE LICENSE IN LICENSE` — FSL has no SPDX identifier, so a bare string makes npm warn. | Keep Apache-2.0; BUSL-1.1; Elastic License 2.0; PolyForm Noncommercial; proprietary | Founder decision 2026-08-03, exercising the veto D-017 explicitly left open ("flagged vetoable in the readiness report since it rode an adopt-all"). Stated intent: **want adoption, do not want an Amazon/MongoDB or Atlassian-style takeover** — someone reselling the product as their own service. Apache-2.0 §2 grants exactly that (perpetual, irrevocable right to sublicense and distribute, commercial use included), so it was the wrong instrument for the goal, not merely a loose one. FSL forbids Competing Use only: internal use at any company, professional services, modification, self-hosting and non-commercial research/education all stay permitted, so adoption is preserved. Chosen over BUSL (more configurable but more text to get wrong), Elastic License 2.0 (never converts), and PolyForm Noncommercial (blocks a company using it internally — kills adoption, overshoots the stated fear). **Timing made this nearly free**: nothing was on npm and the repo had been public for minutes, so the Apache-2.0 grant has essentially no public residue; the window closes at first publish. **OPEN: not reviewed by a lawyer.** The FSL text is the canonical Sentry template fetched from source, not transcribed. |
