# Guided sample project

A built-in idea ("a link-shortener with auth") that runs the real program
end to end, on your own configured model, so you can watch the discipline
before you spend it on your own idea:

1. **Interview** — watch the discovery interview draft VISION, SCOPE, and
   the rest of the phase 0-2 deliverables from a fixed set of answers. No
   typing required for the sample; your real projects go through this live.
2. **Blueprint + decisions** — one run synthesizes the blueprint, then picks
   the technical slate option the model recommends; this walkthrough posts
   the whole run in a single call, so it doesn't pause for an interactive
   slate card the way a decisions-board session does. If the model instead
   raises a decision only a founder can make, the walkthrough has no slate
   UI wired in to resolve it inline — you hit the same gate a real project
   would, and it's reported honestly rather than faked.
3. **Board** — the sample decomposes into 2-3 real tickets on a real board,
   the same lifecycle your own tickets go through. Any gate receipts already
   minted on the sample project (real, hash-chained, never self-attested by
   the phase that produced them) are listed alongside the tickets if present.
4. **Morning queue** — a look at what a night of autonomous work turns into
   the next morning: leverage-sorted cards, approve/reject with no
   navigation required.

Runs on whichever model your server resolves for the pipeline run (its
cheapest/local configuration, if that's what you set up) — the same route a
real project's run uses. If it's local, budget under fifteen minutes. You
can skip this step or come back to it later from Settings -> Setup Wizard;
it ends by asking for your real idea.
